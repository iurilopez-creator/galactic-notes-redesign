# Galactic Notes

A small personal notes app built with Next.js and local browser storage.

## Features

- Create, edit, and delete notes
- Search your notes by title or content
- Duplicate detection to avoid repeated entries
- Notes persist locally in the browser

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Production build

```bash
npm run build
```
